# Hoja de Vida Digital - Anthony Joel Guanoluisa Quimbita

Este proyecto es una hoja de vida digital moderna, elegante e interactiva para presentar un portafolio profesional. Está diseñado para ser responsive, con animaciones suaves, efectos glassmorphism y un estilo moderno inspirado en dashboards tecnológicos.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
- Tailwind CSS
- Font Awesome
- AOS (Animate On Scroll)

## Estructura del proyecto

```
/
│── index.html
│── css/
│   └── style.css
│── js/
│   └── script.js
│── assets/
│   ├── img/
│   ├── icons/
│   └── pdf/
│── README.md
```

## Cómo ejecutar el proyecto

1. Clona o descarga el repositorio.
2. Abre `index.html` en un navegador moderno.
3. Si deseas ejecutar desde un servidor local, puedes usar `Live Server` en VS Code o un servidor simple como `python3 -m http.server`.

## Cómo personalizar la información

- Edita los datos personales directamente en `index.html`.
- Reemplaza `assets/img/profile-placeholder.svg` con una imagen real de perfil.
- Reemplaza `assets/pdf/CV-AnthonyJoel.pdf` con tu currículo en PDF.
- Ajusta los textos de experiencia, educación, habilidades y proyectos.
- Personaliza los colores en `css/style.css`.

## Funcionalidades incluidas

- Diseño moderno con modo oscuro por defecto.
- Navegación suave y barra fija.
- Animaciones de scroll con AOS.
- Efecto de escritura para la descripción profesional.
- Cartas glassmorphism para cada sección.
- Barra de progreso animada para habilidades.
- Formulario de contacto estilizado.
- Botón "Volver arriba".
